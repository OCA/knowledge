Screen Help

Contextual help on the screens of Odoo, written in Odoo or shipped by modules as Markdown files.

A book button in the control panel opens the help of the current screen in a window detached from the Odoo tab, which can stay open beside Odoo.

The help of a screen is made of sections, ordered by sequence, which target:

  • a window action: shown on the screens of this action
  • or a model: shown on every screen of this model, whatever the action

The module shipping the files doesn’t need to depend on ``screen_help``.

Important

This is an alpha version, the data model and design can change at any time without warning. Only for development or testing purpose, do not use in production. More details on development status

Configuration

  • Users of the Help Editor group (and administrators) can write the help: Settings > Technical > User Interface > Help Sections, or the Edit button of the help window.
  • Settings > General Settings > Help > Multilingual Help: a section can be written for a given language. A section without language is shown to everybody. The help is not translated through the standard translation mechanism.
  • Dark mode: the help window follows the color scheme of the user (ir.http.color_scheme()) when a module provides it, e.g. web_dark_mode (OCA/web) or web_enterprise; no dependency on them.

Usage

Read the help: click the book button of the control panel. The button is shown when the screen has some help, or to the help editors.

Write the help in Odoo: Edit button of the help window, then add a section targeting the action or the model of the screen.

Ship the help in a module: add Markdown files in its help directory:

my_module/help/sale.order.md                     # every screen of the model
my_module/help/sale.action_quotations.md         # one window action (xml id)
my_module/help/sale.action_quotations.fr_FR.md   # in French only

You don’t need to depends on screen_help to provide a such files to document your module, just add markdown like above

An optional header orders the sections (sequence 10 by default). In the application help, the screens are ordered by the lowest sequence of their sections, then by the menu order:

---
sequence: 20
---
## My help

When screen_help is installed, the help directory of a module is loaded at each installation / update of the module (and for all the installed modules at the installation of screen_help). Without screen_help, it is ignored.

  • a section loaded from a file can’t be edited in Odoo
  • a file removed from the module removes its section at the next update
  • a file whose model or action doesn’t exist (module not installed) is ignored
  • the headings (#, ##, ###) make the table of contents of the help window

Demo: on a database with demo data, a tour documents each feature on the screen that shows it, each section pointing to the next screen like contacts, /odoo/action-base.action_partner_form
