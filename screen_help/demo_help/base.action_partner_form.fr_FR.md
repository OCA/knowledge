## Aide dans une langue

Cette section n'est visible que des utilisateurs en français : elle vient du fichier
`base.action_partner_form.fr_FR.md`. Elle complète les sections sans langue, montrées à
tout le monde : ce n'est pas une traduction.

Exemple : le **SIRET** est obligatoire pour les sociétés clientes.

Pour choisir la langue d'une section écrite dans Odoo, activez le réglage _Multilingual
Help_ (_Paramètres > Paramètres généraux_, bloc _Help_).
