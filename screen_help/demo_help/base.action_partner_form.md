## Help of a screen

This help is the demo of _Screen Help_: each screen of the demo documents one of its
features. You opened it with the book button of the control panel, shown when the screen
has some help, or always to the help editors.

### Help of an action

This section targets the window action of the screen: a module ships it as the file
`help/base.action_partner_form.md`, named after the xml id of the action.

| Element of the window | Use                                                   |
| --------------------- | ----------------------------------------------------- |
| Sidebar               | table of contents, made from the headings of the help |
| _Print_               | prints the help of the screen                         |
| _Application Help_    | the help of all the screens of the application        |
| _Edit_                | edits the help in the Odoo tab (help editors only)    |

The window stays open beside Odoo: keep it while you work.
