Contextual help on the screens of Odoo, written in Odoo or shipped by
modules as Markdown files.

A book button in the control panel opens the help of the current screen
in a window detached from the Odoo tab, which can stay open beside Odoo.

The help of a screen is made of sections, ordered by sequence, which
target:

- a window action: shown on the screens of this action
- or a model: shown on every screen of this model, whatever the action

A section is either written in Odoo by the help editors (HTML editor),
or shipped by a module as a Markdown file: converted to HTML when the
module is installed or updated, read-only in Odoo, and removed with the
module. The module shipping the files doesn't need to depend on
``screen_help``.

   Only for development or testing purpose, do not use in production.

Configuration
=============

- Users of the *Help Editor* group (and administrators) can write the
  help: *Settings > Technical > User Interface > Help Sections*, or the
  *Edit* button of the help window.
- *Settings > General Settings > Help > Multilingual Help*: a section
  can be written for a given language. A section without language is
  shown to everybody. The help is not translated through the standard
  translation mechanism.
- Dark mode: the help window follows the color scheme of the user
  (``ir.http.color_scheme()``) when a module provides it, e.g.
  ``web_dark_mode`` (OCA/web) or ``web_enterprise``; no dependency on
  them.

Usage
=====

**Read the help**: click the book button of the control panel. The
button is shown when the screen has some help, or to the help editors.

**Write the help in Odoo**: *Edit* button of the help window, then add a
section targeting the action or the model of the screen.

|Help window beside Odoo|

**Ship the help in a module**: add Markdown files in its ``help``
directory:

::

   my_module/help/sale.order.md                     # every screen of the model
   my_module/help/sale.action_quotations.md         # one window action (xml id)
   my_module/help/sale.action_quotations.fr_FR.md   # in French only

An optional header orders the sections (sequence 10 by default). In the
application help, the screens are ordered by the lowest sequence of
their sections, then by the menu order:

.. code:: markdown

   ---
   sequence: 20
   ---
   ## My help

When ``screen_help`` is installed, the ``help`` directory of a module is
loaded at each installation / update of the module (and for all the
installed modules at the installation of ``screen_help``). Without
``screen_help``, it is ignored.

- a section loaded from a file can't be edited in Odoo: edit the file,
  it is reloaded at the next update of the module (its sequence can be
  changed in Odoo meanwhile, the one of the file is applied when the
  file changes)
- a file removed from the module removes its section at the next update
- the sections of a module are removed when it is uninstalled
- a file whose model or action doesn't exist (module not installed) is
  ignored
- the headings (``#``, ``##``, ``###``) make the table of contents of
  the help window

|Section loaded from a file|

**Demo**: on a database with demo data, a tour documents each feature on
the screen that shows it, each section pointing to the next screen:

1. contacts,
   `/odoo/action-base.action_partner_form </odoo/action-base.action_partner_form>`__
   (the *Contacts* app doesn't have to be installed): help of an action,
   of a model, of a language, order of the sections
2. *Settings > Users & Companies > Users*: help written in Odoo
3. *Settings > Users & Companies > Companies*: help of an application,
   look of the window
4. *Settings > Technical > User Interface > Help Sections*: help shipped
   by a module

|Help window in dark mode|

**Migration from ``help_popup``** (OCA/web 8.0): the help of the actions
(``enduser_help`` and ``advanced_help`` columns, left in the database)
becomes help sections of these actions, the advanced help under an
*Advanced Help* heading. It happens when ``screen_help`` is installed,
or when it is updated after renaming the module ``help_popup`` to
``screen_help`` (e.g. in the ``renamed_modules`` of OpenUpgrade). An
action which already has a section written in Odoo is skipped.
