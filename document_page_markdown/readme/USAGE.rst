#. Go to *Knowledge > Pages* and open or create a page.
#. In the page content, type ``/`` and pick *Markdown* under *Structure*.
#. Write (or paste) Markdown in the *Write* tab. The toolbar inserts the syntax
   for you if you prefer.
#. Check the result in the *Preview* tab.
#. Click *Insert*: the formatted content is added at the cursor, as regular page
   content, so history, diffs and reports keep working as usual.
