This module adds a **Markdown** entry to the *Structure* section of the knowledge
page editor's ``/`` menu.

Picking it opens a *Write* / *Preview* box, the same way a pull request
description works: you write `Markdown
<https://daringfireball.net/projects/markdown/>`_, check the formatted result in
the preview, and insert it in the page as regular content.

The preview is rendered server side by the very same renderer that produces the
inserted content, so what you see is what you get.
