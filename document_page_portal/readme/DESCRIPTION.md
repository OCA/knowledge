This module publishes Knowledge document pages (`document.page` records of
type _Content_) to the website portal, so that logged-in portal users can
read them from their _My Account_ area.

A _Knowledge Documents_ entry is added to the portal home, listing the pages
each user is allowed to see, with search and category badges.

Visibility is controlled per page: a page can be shared with **all portal
users** (the _Public_ flag) or restricted to the page's **followers**. Note
that _Public_ here means "any logged-in portal user"; it does **not** expose
pages to anonymous website visitors.
